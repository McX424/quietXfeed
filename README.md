# QuietFeed

Chromium extension for [X](https://x.com) — quieter timeline, same conversation.

## Intent
- Hide **posted** photos / videos / GIFs in the feed (and quote-tweet media)
- Keep avatars, emoji, badges, and normal post formatting
- Nudge the Home timeline to keep showing **newest** posts (e.g. auto “Show new posts”)
